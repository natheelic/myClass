# อธิบายการทำงานของ `fuzzy_fan_control.py` ทีละบรรทัด

ไฟล์ `fuzzy_fan_control.py` ทำหน้าที่สร้างระบบควบคุมความเร็วพัดลมแบบฟัซซี (Fuzzy Logic Controller) โดยรับอินพุตคืออุณหภูมิและความชื้น และประมวลผลคำนวณเอาต์พุตเป็นความเร็วพัดลมด้วย Mamdani Inference และ Centroid Defuzzification ดังนี้:

---

| บรรทัดที่ | โค้ด | คำอธิบาย |
| :---: | :--- | :--- |
| **1-12** | `""" ... """` | คอมเมนต์แบบหลายบรรทัด (Docstring) อธิบายรายละเอียดภาพรวมของโปรแกรม วิธีติดตั้งไลบรารี ข้อมูลอินพุต/เอาต์พุต และเทคนิคที่ใช้ |
| **14** | `import numpy as np` | นำเข้าไลบรารี `numpy` (ย่อเป็น `np`) สำหรับสร้างช่วงตัวเลขและตัวแปรจักรวาลอภิภพ (Universe of Discourse) |
| **15** | `import skfuzzy as fuzz` | นำเข้าไลบรารี `scikit-fuzzy` (ย่อเป็น `fuzz`) เพื่อใช้งานฟังก์ชันตรรกศาสตร์คลุมเครือและการคำนวณค่าสมาชิก |
| **16** | `from skfuzzy import control as ctrl` | นำเข้าโมดูลควบคุม (`control` ย่อเป็น `ctrl`) จาก `skfuzzy` เพื่อใช้สร้างอินพุต, เอาต์พุต และกฎฟัซซี (IF-THEN Rules) |
| **19** | `def build_fan_controller():` | ประกาศฟังก์ชันหลักในการสร้างและตั้งค่าระบบประมวลผลฟัซซีสำหรับควบคุมความเร็วพัดลม |
| **20** | `"""สร้างระบบควบคุมพัดลม คืนค่า ControlSystemSimulation"""` | Docstring อธิบายการทำหน้าที่และตัวแปรที่คืนกลับไปของฟังก์ชัน `build_fan_controller` |
| **23** | `temp = ctrl.Antecedent(np.arange(0, 41, 1), "temp")` | สร้างตัวแปรอินพุต (Antecedent) ชื่อ `"temp"` (อุณหภูมิ) กำหนดช่วงข้อมูลจักรวาลอภิภพจาก 0 ถึง 40 °C (เพิ่มทีละ 1) |
| **24** | `humid = ctrl.Antecedent(np.arange(0, 101, 1), "humid")` | สร้างตัวแปรอินพุต (Antecedent) ชื่อ `"humid"` (ความชื้น) กำหนดช่วงข้อมูลจักรวาลอภิภพจาก 0 ถึง 100 % (เพิ่มทีละ 1) |
| **25** | `fan = ctrl.Consequent(np.arange(0, 101, 1), "fan")` | สร้างตัวแปรเอาต์พุต (Consequent) ชื่อ `"fan"` (ความเร็วพัดลม) กำหนดช่วงข้อมูลเอาต์พุตจาก 0 ถึง 100 % (เพิ่มทีละ 1) |
| **28** | `temp["cold"] = fuzz.trimf(temp.universe, [0, 0, 20])` | กำหนดฟังก์ชันสมาชิกแบบสามเหลี่ยม (Triangular) สำหรับอุณหภูมิ "เย็น" (`cold`) ในพิกัด `[0, 0, 20]` |
| **29** | `temp["warm"] = fuzz.trimf(temp.universe, [10, 20, 30])` | กำหนดฟังก์ชันสมาชิกแบบสามเหลี่ยมสำหรับอุณหภูมิ "อุ่น" (`warm`) ในพิกัด `[10, 20, 30]` |
| **30** | `temp["hot"] = fuzz.trimf(temp.universe, [20, 40, 40])` | กำหนดฟังก์ชันสมาชิกแบบสามเหลี่ยมสำหรับอุณหภูมิ "ร้อน" (`hot`) ในพิกัด `[20, 40, 40]` |
| **32** | `humid["low"] = fuzz.trimf(humid.universe, [0, 0, 60])` | กำหนดฟังก์ชันสมาชิกแบบสามเหลี่ยมสำหรับความชื้น "ต่ำ" (`low`) ในพิกัด `[0, 0, 60]` |
| **33** | `humid["high"] = fuzz.trimf(humid.universe, [40, 100, 100])` | กำหนดฟังก์ชันสมาชิกแบบสามเหลี่ยมสำหรับความชื้น "สูง" (`high`) ในพิกัด `[40, 100, 100]` |
| **35** | `fan["slow"] = fuzz.trimf(fan.universe, [0, 0, 50])` | กำหนดฟังก์ชันสมาชิกแบบสามเหลี่ยมสำหรับเอาต์พุตพัดลมความเร็ว "ช้า" (`slow`) ในพิกัด `[0, 0, 50]` |
| **36** | `fan["medium"] = fuzz.trimf(fan.universe, [25, 50, 75])` | กำหนดฟังก์ชันสมาชิกแบบสามเหลี่ยมสำหรับเอาต์พุตพัดลมความเร็ว "กลาง" (`medium`) ในพิกัด `[25, 50, 75]` |
| **37** | `fan["fast"] = fuzz.trimf(fan.universe, [50, 100, 100])` | กำหนดฟังก์ชันสมาชิกแบบสามเหลี่ยมสำหรับเอาต์พุตพัดลมความเร็ว "เร็ว" (`fast`) ในพิกัด `[50, 100, 100]` |
| **40** | `r1 = ctrl.Rule(temp["hot"] \| humid["high"], fan["fast"])` | สร้างกฎข้อที่ 1 (R1): ถ้าอุณหภูมิร้อน (`hot`) **หรือ** (`\|`) ความชื้นสูง (`high`) แล้วพัดลมต้องเร็ว (`fast`) |
| **41** | `r2 = ctrl.Rule(temp["warm"], fan["medium"])` | สร้างกฎข้อที่ 2 (R2): ถ้าอุณหภูมิอุ่น (`warm`) แล้วพัดลมปานกลาง (`medium`) |
| **42** | `r3 = ctrl.Rule(temp["cold"] & humid["low"], fan["slow"])` | สร้างกฎข้อที่ 3 (R3): ถ้าอุณหภูมิเย็น (`cold`) **และ** (`&`) ความชื้นต่ำ (`low`) แล้วพัดลมทำงานช้า (`slow`) |
| **43** | `r4 = ctrl.Rule(temp["warm"] & humid["high"], fan["fast"])` | สร้างกฎข้อที่ 4 (R4): ถ้าอุณหภูมิอุ่น (`warm`) **และ** (`&`) ความชื้นสูง (`high`) แล้วพัดลมทำงานเร็ว (`fast`) |
| **46** | `system = ctrl.ControlSystem([r1, r2, r3, r4])` | รวมกฎฟัซซีทั้ง 4 ข้อเข้าด้วยกันเพื่อสร้างระบบควบคุม (`ControlSystem`) |
| **47** | `return ctrl.ControlSystemSimulation(system)` | คืนค่าตัวจำลองระบบควบคุม (`ControlSystemSimulation`) ที่พร้อมนำไปคำนวณ |
| **50** | `def fan_speed(sim, temperature, humidity):` | ประกาศฟังก์ชันดึงค่าผลลัพธ์การคำนวณ โดยรับออบเจกต์จำลอง พิกัดอุณหภูมิ และความชื้น |
| **51** | `"""คำนวณความเร็วพัดลมจากอุณหภูมิและความชื้นที่กำหนด"""` | Docstring อธิบายการใช้ประโยชน์ของฟังก์ชันคำนวณความเร็วพัดลม |
| **52** | `sim.input["temp"] = temperature` | ป้อนค่าตัวเลขของอุณหภูมิ (`temperature`) เข้าสู่ตัวแปรระบบนำเข้า `"temp"` |
| **53** | `sim.input["humid"] = humidity` | ป้อนค่าตัวเลขของความชื้น (`humidity`) เข้าสู่ตัวแปรระบบนำเข้า `"humid"` |
| **54** | `sim.compute()` | สั่งประมวลผลระบบควบคุมแบบฟัซซีตามสเต็ปของ Mamdani Inference และหาพื้นที่ผลรวมของกฎ |
| **55** | `return sim.output["fan"]` | ดึงค่าผลลัพธ์สุดท้ายที่ได้จากการแปลงค่าความคลุมเครือกลับเป็นตัวเลข (Defuzzification) ออกมาแล้วคืนค่ากลับ |
| **58** | `if __name__ == "__main__":` | บล็อกตรวจสอบการเรียกใช้ว่าไฟล์ถูกสั่งรันโดยตรง (ไม่ได้รันผ่านการอ้างอิงนำเข้า) |
| **59** | `sim = build_fan_controller()` | เรียกใช้งานฟังก์ชัน `build_fan_controller` เพื่อสร้างออบเจกต์ระบบควบคุมพัดลม |
| **62** | `test_cases = [(28, 70), (18, 30), (38, 90), (22, 80), (10, 20)]` | กำหนดคู่ข้อมูลสำหรับใช้รันกรณีทดสอบ (อุณหภูมิ, ความชื้น) รวม 5 เคสตัวอย่าง |
| **63** | `print(f"{'อุณหภูมิ(°C)':>12} {'ความชื้น(%)':>12} {'พัดลม(%)':>10}")` | พิมพ์หัวคอลัมน์ของตารางบันทึกผลการทดสอบ |
| **64** | `print("-" * 38)` | พิมพ์เส้นแบ่งคั่นข้อหัวตารางความยาว 38 ตัวอักษร |
| **65** | `for t, h in test_cases:` | เริ่มวนลูปทดสอบ โดยดึงข้อมูลอินพุตอุณหภูมิ `t` และ ความชื้น `h` ออกมารันทีละคู่ |
| **66** | `speed = fan_speed(sim, t, h)` | คำนวณความเร็วพัดลมจำลองจากอุณหภูมิและความชื้น ณ เคสนั้น ๆ |
| **67** | `print(f"{t:>12} {h:>12} {speed:>10.1f}")` | พิมพ์ผลทดสอบแสดงค่าอินพุตทั้งคู่พร้อมผลความเร็วพัดลมทศนิยม 1 ตำแหน่ง |
