# อธิบายการทำงานของ `fuzzy_fan_control_simple.py` ทีละบรรทัด

ไฟล์ `fuzzy_fan_control_simple.py` เป็นระบบควบคุมความเร็วพัดลมแบบฟัซซีที่พัฒนาขึ้นด้วย **Python แท้ (Pure Python)** โดยไม่มีการใช้ไลบรารีภายนอก ทำให้เหมาะอย่างยิ่งสำหรับการใช้สอนนักเรียน เพื่อเรียนรู้ขั้นตอนเชิงคณิตศาสตร์และตรรกะเบื้องหลังของ Fuzzy Logic Controller ทั้ง 4 ขั้นตอน:

---

| บรรทัดที่ | โค้ด | คำอธิบาย |
| :---: | :--- | :--- |
| **1-3** | `# fuzzy_fan_control_simple.py ...` | คอมเมนต์หัวไฟล์ อธิบายวัตถุประสงค์เพื่อการเรียนการสอน |
| **6** | `def trimf(x, a, b, c):` | ประกาศฟังก์ชันสมาชิกแบบสามเหลี่ยม (Triangular Membership Function) เพื่อคำนวณหาค่าความจริง $\mu \in [0, 1]$ ณ จุด $x$ |
| **8** | `if x <= a or x >= c:` | กรณีที่ $x$ อยู่นอกขอบเขตฐานสามเหลี่ยม |
| **9** | `return 0.0` | คืนค่าระดับความเป็นสมาชิกเป็น $0$ (ไม่เข้าเกณฑ์เลย) |
| **10** | `elif a < x <= b:` | กรณีที่ $x$ อยู่ในช่วงทางลาดขาขึ้นของสามเหลี่ยม (จากฐานซ้ายขึ้นไปจุดยอด) |
| **11** | `return (x - a) / (b - a) if b > a else 1.0` | คำนวณค่าความเป็นสมาชิกตามอัตราส่วนทางลาดขาขึ้น |
| **12** | `elif b < x < c:` | กรณีที่ $x$ อยู่ในช่วงทางลาดขาลงของสามเหลี่ยม (จากจุดยอดลงไปฐานขวา) |
| **13** | `return (c - x) / (c - b) if c > b else 1.0` | คำนวณค่าความเป็นสมาชิกตามอัตราส่วนทางลาดขาลง |
| **14** | `return 1.0` | คืนค่าความจริงเต็ม $1.0$ (กรณีที่ $x$ ตรงกับจุดยอด $b$ พอดี) |
| **17** | `def fuzzify(temp, humid):` | ประกาศฟังก์ชันขั้นตอนที่ 1: Fuzzification แปลงค่าตัวเลขจริงให้กลายเป็นค่าระดับความจริงฟัซซี |
| **18-23**| `mu_temp = { ... }` | คำนวณระดับความเป็นสมาชิกของอุณหภูมิสำหรับ 3 เซต: เย็น (`cold`), อุ่น (`warm`), และร้อน (`hot`) ตามสูตรสามเหลี่ยม |
| **25-29**| `mu_humid = { ... }` | คำนวณระดับความเป็นสมาชิกของความชื้นสำหรับ 2 เซต: ต่ำ (`low`) และสูง (`high`) ตามสูตรสามเหลี่ยม |
| **31** | `return mu_temp, mu_humid` | คืนค่าดิชันนารีระดับความเป็นสมาชิกของอุณหภูมิและความชื้น |
| **34** | `def evaluate_rules(mu_temp, mu_humid):` | ประกาศฟังก์ชันขั้นตอนที่ 2 & 3: ประเมินกฎ IF-THEN และรวบรวมผลลัพธ์ (Rule Evaluation & Aggregation) |
| **36** | `r1 = max(mu_temp["hot"], mu_humid["high"])` | กฎข้อ 1: ร้อน **OR** ชื้นสูง (ใช้ตัวดำเนินการ `max` แทนคำว่า OR ในตรรกศาสตร์ฟัซซี) |
| **39** | `r2 = mu_temp["warm"]` | กฎข้อ 2: อุณหภูมิอุ่น (ดึงระดับความเป็นสมาชิกของอุ่นมาใช้โดยตรง) |
| **42** | `r3 = min(mu_temp["cold"], mu_humid["low"])` | กฎข้อ 3: เย็น **AND** ชื้นต่ำ (ใช้ตัวดำเนินการ `min` แทนคำว่า AND ในตรรกศาสตร์ฟัซซี) |
| **45** | `r4 = min(mu_temp["warm"], mu_humid["high"])` | กฎข้อ 4: อุ่น **AND** ชื้นสูง (ใช้ตัวดำเนินการ `min` แทนคำว่า AND ในตรรกศาสตร์ฟัซซี) |
| **47-52**| `fan_activation = { ... }` | ขั้นตอน Aggregation: รวมผลการกระตุ้นพัดลม สำหรับระดับ "เร็ว" ที่ได้จาก R1 และ R4 จะใช้ค่าสูงสุด `max(r1, r4)` |
| **54** | `return fan_activation` | คืนค่าความแรงในการกระตุ้นพัดลมทั้ง 3 ระดับ (ช้า, กลาง, เร็ว) |
| **58** | `def defuzzify_centroid(fan_activation):` | ประกาศฟังก์ชันขั้นตอนที่ 4: Defuzzification แปลงค่าผลลัพธ์ฟัซซีกลับเป็นค่าพัดลมจริงด้วยวิธีจุดศูนย์ถ่วง (Centroid) |
| **59-60**| `numerator = 0.0 ...` | กำหนดตัวสะสมผลรวมแบบถ่วงน้ำหนัก (เศษ) และผลรวมระดับค่าสมาชิกสะสม (ส่วน) |
| **63** | `for x in range(0, 101):` | จำลองการสแกนความเร็วพัดลมที่เป็นไปได้ทีละ 1% ตั้งแต่ 0% ถึง 100% |
| **64-67**| `mu_slow = ...` | คำนวณกราฟความเร็วพัดลม ณ ตำแหน่งเปอร์เซ็นต์ $x$ สำหรับเกณฑ์ ช้า, กลาง, และเร็ว |
| **69-72**| `y_slow = ...` | นำค่าระดับการกระตุ้นของกฎมา "ตัดยอด" กราฟพัดลม ณ จุด $x$ (การประยุกต์ใช้ Mamdani Inference ด้วย `min`) |
| **74** | `y_agg = max(y_slow, y_medium, y_fast)` | รวมพื้นที่ผลลัพธ์ ณ จุด $x$ จากทุกระดับความเร็วเข้าด้วยกันโดยหาค่าสูงสุด (`max`) |
| **77** | `numerator += x * y_agg` | คำนวณผลรวมโมเมนต์เชิงฟัซซี (ตำแหน่งความเร็วพัดลมคูณด้วยระดับความจริงรวม ณ จุดนั้น) |
| **78** | `denominator += y_agg` | สะสมพื้นที่ระดับความจริงรวมของจุด $x$ ทั้งหมด |
| **80** | `if denominator == 0.0:` | ตรวจสอบกรณีหารด้วยศูนย์ (หากไม่มีกฎข้อใดทำงานหรือเข้าเกณฑ์เลย) |
| **81** | `return 0.0` | ป้องกันการ Error โดยให้คืนค่าผลลัพธ์พัดลมเป็น 0% |
| **83** | `return numerator / denominator` | คืนค่าจุดกึ่งกลางของพื้นที่ผลรวมความสูง (ผลลัพธ์เปอร์เซ็นต์พัดลม) |
| **86** | `def calculate_fan_speed(temperature, humidity):` | ฟังก์ชันอำนวยความสะดวกที่รวบรวมฟังก์ชันย่อยเข้าไว้ด้วยกัน |
| **88-95**| `mu_temp, mu_humid = ...` | เรียกกระบวนการ Fuzzify -> Evaluate Rules -> Defuzzify ทีละสเต็ปตามลำดับ และส่งข้อมูลอธิบายพร้อมผลลัพธ์กลับไป |
| **98** | `if __name__ == "__main__":` | บล็อกตรวจสอบการสั่งรันโค้ดตรง ๆ จากตัวประมวลผล |
| **101** | `t, h = 28, 70` | กำหนดอินพุตตัวอย่างเพื่อใช้อธิบายในห้องเรียน (อุณหภูมิ 28°C, ความชื้น 70%) |
| **102** | `speed, mu_t, mu_h, act = ...` | สั่งให้ระบบคำนวณและนำรายละเอียดสเต็ปมาแสดงผล |
| **104-115**| `print(...)` | พิมพ์รายงานการทำงานแยกทีละสเต็ป เพื่อให้นักเรียนเข้าใจกระบวนการคำนวณของแต่ละขั้นอย่างเห็นภาพ |
