# อธิบายการทำงานของ `dfs.py` ทีละบรรทัด

ไฟล์ `dfs.py` ประกอบด้วยอัลกอริทึมค้นหาแบบแนวลึก (Depth-First Search) สองเวอร์ชัน คือแบบ Recursion และแบบ Iterative:

---

### 1. แบบ Recursion (`dfs_recursive`)

| บรรทัดที่ | โค้ด | คำอธิบาย |
| :---: | :--- | :--- |
| **14** | `def dfs_recursive(G, start, goal):` | ประกาศฟังก์ชัน DFS เวอร์ชันเรียกใช้งานซ้ำตัวเอง |
| **18** | `visited = set()` | เซ็ตเก็บชื่อโหนดที่เคยประมวลผลแล้วเพื่อไม่ให้เกิดลูปไม่สิ้นสุด |
| **19** | `order = []` | เก็บประวัติขั้นตอนการเดินทางแวะเยี่ยมโหนด |
| **21** | `def visit(node, path):` | ประกาศฟังก์ชันภายในที่จะถูกเรียกทำงานทับซ้อนตัวเอง |
| **22** | `visited.add(node)` | ทำเครื่องหมายโหนดปัจจุบันว่าเข้าเยี่ยมแล้ว |
| **23** | `order.append(node)` | เก็บเข้าประวัติลำดับการเยี่ยมโหนด |
| **25** | `if node == goal:` | ตรวจจับว่าถ้าเจอโหนดเป้าหมายแล้ว |
| **26** | `return list(path)` | ส่งออกเส้นทางสะสมปัจจุบันในรูปคัดลอกลิสต์ใหม่ |
| **28** | `for neighbor in sorted(G.neighbors(node)):` | วนลูปโหนดเพื่อบ้านโดยเรียงตามลำดับอักษร |
| **29** | `if neighbor not in visited:` | เช็กว่าเพื่อนบ้านคนนี้ยังไม่เคยถูกเยี่ยมมาก่อน |
| **30** | `result = visit(neighbor, path + [neighbor])` | แวะตรวจเข้าไปในกิ่งเพื่อนบ้านต่อ พ่วงโหนดใหม่ลงในเส้นทาง |
| **31** | `if result is not None:` | ตรวจว่าหากประมวลผลค้นหาแล้วได้รับคำตอบกลับมา (ไม่ใช่ None) |
| **32** | `return result` | ส่งผลลัพธ์ที่เป็นเส้นทางย้อนกลับขึ้นไปหาผู้รับด้านบน |
| **33** | `return None` | หากประมวลผลหมดทุกเพื่อนบ้านแล้วไม่เจอ คืนค่าว่างบ่งบอกทางนี้ตัน |
| **35** | `path = visit(start, [start])` | เริ่มรันฟังก์ชันภายในครั้งแรกสุดป้อนโหนดจุดเริ่ม `start` |
| **36** | `return path, order` | คืนค่าลิสต์ของเส้นทางและประวัติการทำงาน |

### 2. แบบ Iterative วนลูปด้วย Stack (`dfs_iterative`)

| บรรทัดที่ | โค้ด | คำอธิบาย |
| :---: | :--- | :--- |
| **39** | `def dfs_iterative(G, start, goal):` | ประกาศฟังก์ชัน DFS เวอร์ชันใช้ลูปและสแตก |
| **44** | `stack = [[start]]` | สร้างลิสต์ Stack (LIFO) โดยเก็บทั้งก้อนของเส้นทางเริ่มต้น |
| **45** | `visited = set()` | เซ็ตเก็บข้อมูลโหนดที่ประมวลผลตรวจสอบแล้ว |
| **46** | `order = []` | ลิสต์เก็บเรียงลำดับการขยายโหนด |
| **48** | `while stack:` | วนลูปตราบใดที่ยังมีเส้นทางค้างคาคอยให้ไปประเมินในสแตก |
| **49** | `path = stack.pop()` | ดึงข้อมูลชิ้นสุดท้ายออกจากสแตก (LIFO) ได้เป็นเส้นทางปัจจุบัน |
| **50** | `node = path[-1]` | เลือกดูโหนดตัวสุดท้ายในเส้นทางปัจจุบันที่ถูกดึงออกมา |
| **52** | `if node in visited:` | ตรวจสอบว่าโหนดปลายนี้ได้รับการทำงานแล้วหรือยัง |
| **53** | `continue` | ถ้าใช่ ให้ละการประมวลผลรอบนี้แล้วข้ามไปทำงานรอบต่อไป |
| **54** | `visited.add(node)` | เครื่องหมายว่าโหนดปลายปัจจุบันถูกตรวจแล้ว |
| **55** | `order.append(node)` | นำใส่ข้อมูลเรียงลำดับผล |
| **57** | `if node == goal:` | ถ้าเป็นปลายทางเป้าหมายที่เราตามหา |
| **58** | `return path, order` | คืนค่าเส้นทางนี้พร้อมประวัติทันที |
| **61** | `for neighbor in sorted(G.neighbors(node), reverse=True):` | วนลูปเพื่อนบ้านแบบเรียงอักษรจากท้ายไปหน้า (เพื่อให้ตัวอักษรแรก ๆ รันก่อนเมื่อดึงสแตก) |
| **62** | `if neighbor not in visited:` | หากยังไม่เคยโดนเยี่ยม |
| **63** | `stack.append(path + [neighbor])` | สร้างเส้นทางใหม่ต่อท้ายด้วยโหนดเพื่อนบ้านนั้นใส่ลงท้ายสแตก |
| **65** | `return None, order` | คืนค่าว่างกรณีค้นหาจนหมดระบบแล้วยังเข้าไม่ถึงเป้าหมาย |
