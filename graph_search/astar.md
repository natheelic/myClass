# อธิบายการทำงานของ `astar.py` ทีละบรรทัด

ไฟล์ `astar.py` บรรจุอัลกอริทึมการหาเส้นทางที่ดีที่สุดตามพฤติกรรมของ A* Search Algorithm:

---

| บรรทัดที่ | โค้ด | คำอธิบาย |
| :---: | :--- | :--- |
| **1-11** | `""" ... """` | คอมเมนต์แนะนำแนวคิดหลักของอัลกอริทึม A* (g(n) + h(n)) และการใช้ heap |
| **13** | `import heapq` | นำเข้าระบบจัดการข้อมูลแบบ Min-Heap เพื่อการจัดการคิวตามความสำคัญ |
| **14** | `import itertools` | นำเข้าระบบวนรอบช่วยสร้างตัวเลขเพิ่มขึ้นอัตโนมัติ |
| **16** | `from graph_builder import euclidean, get_positions` | ดึงพิกัดและฟังก์ชันระยะตรงจากไฟล์อื่นมาทำงานร่วมกัน |
| **19** | `def astar(G, start, goal):` | ประกาศฟังก์ชันค้นหา A* รับกราฟ, จุดเริ่ม, และเป้าหมาย |
| **26** | `pos = get_positions(G)` | ดึงพิกัดระบุตำแหน่งของแต่ละโหนดเก็บในตัวแปร |
| **28** | `def h(node):` | ประกาศฟังก์ชันภายในคำนวณคาดเดาความใกล้ (Heuristic) |
| **29** | `return euclidean(pos[node], pos[goal])` | หาระยะห่างทางตรงแบบ Euclidean เป็นค่าคาดการณ์ไปหาเป้าหมาย |
| **31** | `counter = itertools.count()` | กำหนดตัวสร้างตัวเลขลำดับ (0, 1, 2, ...) สำหรับใช้เป็นตัวเปรียบเทียบลำดับที่สองใน Heap |
| **33** | `open_heap = [(h(start), 0.0, next(counter), start, [start])]` | ใส่โหนดแรกเป็นสมาชิกในคิว ประกอบด้วยค่า (f, g, ลำดับ, โหนดเริ่มต้น, ลิสต์เส้นทาง) |
| **34** | `best_g = {start: 0.0}` | เก็บต้นทุนเดินทางจากจุดเริ่มต้นจริงสะสมที่ถูกที่สุดของแต่ละโหนด |
| **35** | `order = []` | ลิสต์เก็บบันทึกประวัติขั้นตอนการดึงโหนดออกมาประมวลผล |
| **37** | `while open_heap:` | วนลูปประมวลผลตราบใดที่ยังมีโหนดค้างคาในคิวรอประเมิน |
| **38** | `f, g, _, node, path = heapq.heappop(open_heap)` | ดึงชุดข้อมูลที่ให้ค่าคำนวณประเมิน $f(n)$ ต่ำสุดออกจาก heap เสมอ |
| **39** | `order.append(node)` | บันทึกประวัติโหนดนี้ว่าถูกขยายการสำรวจแล้ว |
| **41** | `if node == goal:` | ตรวจว่าถึงโหนดที่หมายปลายทางแล้วหรือไม่ |
| **42** | `return path, order, round(g, 2)` | คืนค่าลิสต์เส้นทางที่ประหยัดสุด, ลำดับการขยาย, และค่าต้นทุนสะสมรวมปัดเศษ |
| **44** | `for neighbor in G.neighbors(node):` | วนลูปตรวจสอบโหนดข้างเคียงที่เชื่อมกันอยู่ |
| **45** | `weight = G[node][neighbor]["weight"]` | ดึงคุณสมบัติค่าน้ำหนักจริงของถนนเส้นเชื่อมนี้ |
| **46** | `new_g = g + weight` | นำค่าต้นทุนสะสมจริงมารวมเพิ่มกับน้ำหนักเส้นเชื่อมนี้ เกิดเป็นราคาเดินใหม่ |
| **48** | `if neighbor not in best_g or new_g < best_g[neighbor]:` | หากไม่เคยพบหรือหนทางนี้ถูกกว่าหนทางเดิมที่เคยจำประวัติได้ |
| **49** | `best_g[neighbor] = new_g` | ปรับปรุงค่าใช้จ่ายที่ดีที่สุดสำหรับโหนดนี้ |
| **50** | `new_f = new_g + h(neighbor)` | หาค่าพยากรณ์ใหม่ $f(neighbor) = g + h$ |
| **51-54**| `heapq.heappush(...)` | นำชุดค่าประเมินและทิศทางใหม่ ใส่กลับเข้าไปเก็บในคิว Priority Queue |
| **56** | `return None, order, None` | หากประมวลผลไปจน heap ว่างเปล่าแต่หาทางเดินไม่ได้ คืนค่าว่าง |
| **59-67**| `if __name__ == "__main__":` ... | บล็อกทดลองรันประมวลผลอัลกอริทึม A* เดี่ยว ๆ และแสดงข้อความรายงาน |
