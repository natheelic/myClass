# อธิบายการทำงานของ `bfs.py` ทีละบรรทัด

ไฟล์ `bfs.py` ประกอบด้วยอัลกอริทึมการค้นหาแบบแนวกว้าง (Breadth-First Search) โดยการสำรวจโหนดในแนวกว้างทีละชั้น ดังนี้:

---

| บรรทัดที่ | โค้ด | คำอธิบาย |
| :---: | :--- | :--- |
| **1-8** | `""" ... """` | คอมเมนต์อธิบายคุณสมบัติการทำงานของ BFS และจุดประสงค์ |
| **10** | `from collections import deque` | นำเข้าคลาส `deque` เพื่อใช้เป็นโครงสร้างข้อมูลคิวที่เร็วและมีประสิทธิภาพ |
| **13** | `def bfs(G, start, goal):` | ประกาศฟังก์ชัน BFS รับพารามิเตอร์ กราฟ `G`, จุดเริ่ม `start` และเป้าหมาย `goal` |
| **14-18**| `"""..."""` | อธิบายการคืนค่าของฟังก์ชัน (เส้นทางที่ได้ และ ลำดับการขยายโหนด) |
| **19** | `queue = deque([start])` | สร้างคิวเริ่มต้นขึ้นมา โดยใส่โหนดแรกเข้าไปรอประมวลผล |
| **20** | `visited = {start}` | เซ็ตสำหรับบันทึกโหนดที่เคยเจอแล้วเพื่อป้องกันการแวะซ้ำซ้อน |
| **21** | `parent = {start: None}` | ดิกชันนารีสำหรับโยงความสัมพันธ์โหนดลูกหาโหนดพ่อเพื่อใช้ย้อนเส้นทางกลับ |
| **22** | `order = []` | ลิสต์เก็บลำดับโหนดที่ถูกประมวลผลจริงเพื่อใช้ศึกษาการเคลื่อนไหวของระบบ |
| **24** | `while queue:` | วนลูปทำงานตราบใดที่ยังมีโหนดค้างอยู่ในคิวรอการตรวจสอบ |
| **25** | `node = queue.popleft()` | ดึงโหนดที่อยู่ด้านซ้ายสุดหรือหัวคิวออกมาทำงาน (FIFO) |
| **26** | `order.append(node)` | เพิ่มโหนดที่เพิ่งดึงออกมาใส่ในลิสต์บันทึกประวัติ `order` |
| **28** | `if node == goal:` | ตรวจสอบว่าโหนดปัจจุบันที่ดึงออกมาเป็นโหนดเป้าหมายแล้วหรือไม่ |
| **29** | `return _reconstruct(parent, goal), order` | ถ้าใช่ ให้เรียกฟังก์ชันประกอบเส้นทางกลับ และคืนค่าเส้นทางพร้อมประวัติ |
| **31** | `for neighbor in sorted(G.neighbors(node)):` | วนลูปเพื่อนบ้านของโหนดนี้ โดยเรียงลำดับตัวอักษรเพื่อให้ผลคงที่เสมอ |
| **32** | `if neighbor not in visited:` | ถ้าเพื่อนบ้านโหนดนี้ยังไม่เคยอยู่ในลิสต์แวะผ่านมาก่อน |
| **33** | `visited.add(neighbor)` | มาร์กเพื่อนบ้านรายนี้ลงในเซ็ต `visited` ว่าตรวจเจอแล้ว |
| **34** | `parent[neighbor] = node` | บันทึกว่าผู้เป็นโหนดพ่อแม่ของ `neighbor` ตัวนี้คือ `node` |
| **35** | `queue.append(neighbor)` | นำเพื่อนบ้านที่ค้นพบนี้ใส่เข้าไปที่ท้ายคิวเพื่อรอประมวลผลในรอบถัดไป |
| **37** | `return None, order` | หากทำงานจนคิวหมดแล้วยังไม่ถึงเป้าหมาย ให้คืนค่าเส้นทางเป็น `None` |
| **40** | `def _reconstruct(parent, goal):` | ฟังก์ชันย่อยสำหรับประกอบเส้นทางย้อนกลับขึ้นไปหาจุดเริ่มต้น |
| **42** | `path = []` | กำหนดลิสต์ผลลัพธ์ว่างเปล่า |
| **43** | `node = goal` | เริ่มต้นขยับตัวแปรที่ปลายทาง (โหนดเป้าหมาย) |
| **44** | `while node is not None:` | วนลูปย้อนพ่อแม่ไปเรื่อย ๆ จนกว่าจะเจอต้นขั้วแรกสุด (`None`) |
| **45** | `path.append(node)` | ใส่โหนดที่ขยับเข้าหาลงในลิสต์เส้นทาง |
| **46** | `node = parent[node]` | ขยับตัวแปรเดินถอยกลับไปยังโหนดพ่อแม่ของตัวปัจจุบัน |
| **47** | `return path[::-1]` | กลับด้านของลิสต์เพราะเราค้นหาย้อนหลังจากเป้าหมายกลับหาจุดเริ่ม |
| **50-59**| `if __name__ == "__main__":` ... | บล็อกทดสอบรันผลการค้นหา BFS แยกต่างหาก และแสดงผลสรุปบนเทอร์มินัล |
