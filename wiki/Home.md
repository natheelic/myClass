## โครงสร้างเว็บไซต์

เว็บไซต์เป็น Static Site โดยมี `index.html` ที่ root เป็นจุดเริ่มต้น และแยกเนื้อหาแต่ละรายวิชา/หัวข้อไว้ในไดเรกทอรีของตนเอง

| ตำแหน่ง | เนื้อหา |
| --- | --- |
| `index.html` | หน้าแรกของเว็บไซต์ |
| `markdown.css` | รูปแบบการแสดงผลร่วมสำหรับเอกสาร Markdown ที่ render เป็น HTML |
| `31909-1001/` | รายวิชาระบบปฏิบัติการ |
| `31909-2004/` | เนื้อหาอัลกอริทึม, Fuzzy Logic และ Machine Learning |
| `21909-1004/` | เนื้อหาการวิเคราะห์และออกแบบระบบ |
| `electronics/` | บันทึกและเครื่องมือเกี่ยวกับอิเล็กทรอนิกส์ |

## การเผยแพร่ด้วย GitLab Pages

ไม่ต้องสร้างหรือ commit โฟลเดอร์ `public` ใน repository

Pipeline ใน `.gitlab-ci.yml` จะทำงานเมื่อ push ไปยัง default branch ดังนี้:

1. สร้างโฟลเดอร์ `public` ชั่วคราวใน GitLab CI runner
2. คัดลอกไฟล์ที่ commit แล้วทั้งหมดไปยัง `public`
3. เผยแพร่เนื้อหาใน `public` ผ่าน GitLab Pages

ดังนั้นเมื่อเพิ่มหน้าใหม่ ให้ commit ไฟล์ HTML, CSS, JavaScript หรือ asset ไว้ในตำแหน่งจริงของเว็บไซต์ตามปกติ แล้วเพิ่มลิงก์จากหน้า index ที่เกี่ยวข้อง

## แนวทางเพิ่มเอกสารใหม่

1. สร้างไฟล์ Markdown ต้นฉบับในโฟลเดอร์รายวิชา
2. สร้างหน้า HTML ที่ render เนื้อหา โดยใช้ `markdown.css` และรูปแบบเอกสารเดียวกับหน้าเดิม
3. เพิ่มลิงก์ไปยังหน้า HTML จาก index ของรายวิชาและ/หรือหน้าแรก
4. ตรวจสอบลิงก์ภายในก่อน commit และ push
