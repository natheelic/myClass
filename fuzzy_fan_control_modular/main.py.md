# อธิบายการทำงานของ `main.py` ทีละบรรทัด

ไฟล์ [main.py](file:///Users/natheesrina/Sources/python-scripts/myClass/fuzzy_fan_control_modular/main.py) ทำหน้าที่เป็นโปรแกรมจำลองหลักในการเรียกใช้งานฟังก์ชันของ Fuzzy Logic Engine นำค่าพารามิเตอร์จำลองตัวเลขเข้ามาประมวลผล และแสดงผลรายงานความคืบหน้าทีละขั้นตอน ดังนี้:

---

| บรรทัดที่ | โค้ด | คำอธิบาย |
| :---: | :--- | :--- |
| **1-3** | `# main.py ...` | คอมเมนต์แสดงหัวข้อและรายละเอียดเบื้องต้นของโปรแกรม |
| **5** | `import fuzzy_engine as engine` | นำเข้าโมดูล [fuzzy_engine.py](file:///Users/natheesrina/Sources/python-scripts/myClass/fuzzy_fan_control_modular/fuzzy_engine.py) (ตั้งชื่อย่อว่า `engine`) เพื่อเรียกใช้งานฟังก์ชันคำนวณ |
| **7** | `def run_simulation(temp, humid):` | ประกาศฟังก์ชันจำลองหลัก รับอินพุตเป็นค่าอุณหภูมิและความชื้น |
| **11** | `mu_temp, mu_humid = engine.fuzzify(temp, humid)` | เรียกขั้นตอนที่ 1: Fuzzify เพื่อแปลงค่าอินพุตจริงเป็นเกรดความจริงฟัซซีของอุณหภูมิและความชื้น |
| **14** | `activation = engine.evaluate_rules(mu_temp, mu_humid)` | เรียกขั้นตอนที่ 2 & 3: ประเมินกฎฟัซซีควบคุม 4 ข้อ และหาความสูงของการกระตุ้นความเร็วพัดลม |
| **17** | `speed = engine.defuzzify(activation)` | เรียกขั้นตอนที่ 4: Defuzzify คำนวณหาน้ำหนักศูนย์กลางความเร็วพัดลมจริงออกมาเป็นเปอร์เซ็นต์ |
| **20-29**| `print(...)` | แสดงข้อมูลรายงานสรุปผลลัพธ์การประมวลผลอย่างละเอียดทีละขั้นตอนออกหน้าจอเพื่อส่งเสริมความเข้าใจของผู้เรียน |
| **31** | `if __name__ == "__main__":` | บล็อกตรวจสอบการสั่งรันโปรแกรมว่าถูกรันโดยตรง (ไม่ได้รันผ่านการอ้างอิงนำเข้า) |
| **33** | `run_simulation(28, 70)` | เรียกฟังก์ชันจำลองตัวอย่างด้วยข้อมูล อุณหภูมิ 28°C และความชื้น 70% |
