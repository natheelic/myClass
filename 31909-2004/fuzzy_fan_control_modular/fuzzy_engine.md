# อธิบายการทำงานของ `fuzzy_engine.py` ทีละบรรทัด

ไฟล์ [fuzzy_engine.py](file:///Users/natheesrina/Sources/python-scripts/myClass/fuzzy_fan_control_modular/fuzzy_engine.py) ทำหน้าที่คำนวณคณิตศาสตร์และประมวลผลตรรกศาสตร์คลุมเครือทั้งหมด (Fuzzy Logic Engine) โดยแบ่งฟังก์ชันการคำนวณออกตามทฤษฎีหลัก ดังนี้:

---

| บรรทัดที่ | โค้ด | คำอธิบาย |
| :---: | :--- | :--- |
| **6** | `def trimf(x, a, b, c):` | ประกาศฟังก์ชันสำหรับคำนวณค่าความเป็นสมาชิกแบบสามเหลี่ยม (Triangular Membership Function) |
| **8-9** | `if x <= a or x >= c: return 0.0` | หากค่า $x$ อยู่นอกพิกัดฐานสามเหลี่ยมด้านซ้ายและขวา ให้คืนค่าระดับสมาชิกเป็น $0.0$ (ไม่เข้าเกณฑ์เลย) |
| **10-11**| `elif a < x <= b: return (x - a) / (b - a) ...` | หาก $x$ อยู่ช่วงทางลาดขาขึ้น (ระหว่างจุดเริ่มฐาน $a$ และยอด $b$) ให้คำนวณค่าสมาชิกตามสัดส่วนทางลาดขึ้น |
| **12-13**| `elif b < x < c: return (c - x) / (c - b) ...` | หาก $x$ อยู่ช่วงทางลาดขาลง (ระหว่างยอด $b$ และฐานปลาย $c$) ให้คำนวณค่าสมาชิกตามสัดส่วนทางลาดลง |
| **14** | `return 1.0` | คืนค่าระดับสมาชิกเต็ม $1.0$ (กรณีที่ $x$ ตรงกับตำแหน่งจุดยอด $b$ พอดี) |
| **16** | `def fuzzify(temp, humid):` | ประกาศฟังก์ชันขั้นตอนที่ 1: แปลงค่าตัวเลขอินพุตจริง (อุณหภูมิ, ความชื้น) เป็นระดับความจริงฟัซซี (Fuzzification) |
| **18-22**| `mu_temp = { ... }` | คำนวณหาค่าความจริงของอุณหภูมิสำหรับระดับ "เย็น" (0,0,20), "อุ่น" (10,20,30), และ "ร้อน" (20,40,40) |
| **23-26**| `mu_humid = { ... }` | คำนวณหาค่าความจริงของความชื้นสำหรับระดับ "ต่ำ" (0,0,60) และ "สูง" (40,100,100) |
| **27** | `return mu_temp, mu_humid` | คืนค่าระดับความเป็นสมาชิกของทั้งสองตัวแปรอินพุตกลับไปในรูปแบบ Dictionary |
| **29** | `def evaluate_rules(mu_temp, mu_humid):` | ประกาศฟังก์ชันขั้นตอนที่ 2 & 3: ประเมินกฎควบคุม (Inference & Aggregation) |
| **32** | `r1 = max(mu_temp["hot"], mu_humid["high"])` | กฎข้อ 1: ร้อน **OR** ชื้นสูง (ในตรรกศาสตร์ฟัซซี คำว่า OR จะแทนด้วยฟังก์ชันหาค่าสูงสุด `max`) |
| **34** | `r2 = mu_temp["warm"]` | กฎข้อ 2: อุณหภูมิอุ่น (ดึงระดับความเป็นสมาชิกของ "อุ่น" มาใช้โดยตรง) |
| **36** | `r3 = min(mu_temp["cold"], mu_humid["low"])` | กฎข้อ 3: เย็น **AND** ชื้นต่ำ (ในตรรกศาสตร์ฟัซซี คำว่า AND จะแทนด้วยฟังก์ชันหาค่าต่ำสุด `min`) |
| **38** | `r4 = min(mu_temp["warm"], mu_humid["high"])` | กฎข้อ 4: อุ่น **AND** ชื้นสูง (ใช้ฟังก์ชันหาค่าต่ำสุด `min`) |
| **40-44**| `return { ... "fast": max(r1, r4) }` | รวบรวมระดับความแรงพัดลม และคืนค่ากลับไป (ระดับ "เร็ว" ที่เกิดซ้ำกันจาก R1 และ R4 จะรวมด้วยค่าสูงสุด `max`) |
| **46** | `def defuzzify(activation):` | ประกาศฟังก์ชันขั้นตอนที่ 4: แปลงค่าฟัซซีกลับเป็นค่าจริง % ด้วยวิธีหาจุดศูนย์ถ่วง (Centroid Defuzzification) |
| **47-48**| `numerator = 0.0 ...` | กำหนดตัวแปรสะสมผลคูณค่าโมเมนต์ (เศษ) และตัวแปรสะสมพื้นที่ระดับสมาชิกสะสม (ส่วน) |
| **51** | `for x in range(0, 101):` | วนลูปสแกนเปอร์เซ็นต์พัดลมที่เป็นไปได้ทีละ 1% ตั้งแต่ 0% ถึง 100% เพื่อคำนวณหาพื้นที่ศูนย์ถ่วงใต้กราฟ |
| **53-55**| `mu_slow = trimf(...)` | คำนวณความสูงตามธรรมชาติของกราฟสมาชิกพัดลม (ช้า, กลาง, เร็ว) ณ ความเร็ว $x$ |
| **58-62**| `y_agg = max(...)` | ตัดยอดความสูงของแต่ละพัดลมตามกฎจำลอง (`min`) และรวมกราฟพื้นที่เข้าด้วยกัน ณ จุด $x$ (`max`) |
| **65-66**| `numerator += x * y_agg ...` | สะสมโมเมนต์เชิงฟัซซี ($x \times y$) และสะสมผลรวมความสูงพื้นที่ ($y$) |
| **68** | `return numerator / denominator ...` | คืนค่าตำแหน่งจุดศูนย์ถ่วง (เปอร์เซ็นต์ความเร็วพัดลมจริง) หากไม่มีกฎทำงานเลยจะคืนค่า 0.0 เพื่อเลี่ยงหารด้วยศูนย์ |
