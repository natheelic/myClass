# อธิบายการทำงานของ `main.py` ทีละบรรทัด (แบบอินเทอร์แอคทีฟ)

ไฟล์ [main.py](file:///Users/natheesrina/Sources/python-scripts/myClass/fuzzy_fan_control_modular/main.py) ทำหน้าที่เป็นโปรแกรมจำลองหลักที่เปิดให้รับค่าอินพุตอุณหภูมิและความชื้นผ่านทางคีย์บอร์ด (Interactive) แล้วส่งไปคำนวณใน Fuzzy Logic Engine พร้อมรายงานความคืบหน้าทีละขั้นตอน ดังนี้:

---

| บรรทัดที่ | โค้ด | คำอธิบาย |
| :---: | :--- | :--- |
| **1-4** | `# main.py ...` | คอมเมนต์แสดงหัวข้อและรายละเอียดเบื้องต้นของโปรแกรมหลักแบบอินเทอร์แอคทีฟ |
| **6** | `import fuzzy_engine as engine` | นำเข้าโมดูล [fuzzy_engine.py](file:///Users/natheesrina/Sources/python-scripts/myClass/fuzzy_fan_control_modular/fuzzy_engine.py) (ย่อเป็น `engine`) เพื่อเรียกใช้งานฟังก์ชันคำนวณ |
| **8** | `def run_simulation(temp, humid):` | ประกาศฟังก์ชันจำลองหลัก รับอินพุตเป็นค่าอุณหภูมิและความชื้น |
| **12** | `mu_temp, mu_humid = engine.fuzzify(temp, humid)` | เรียกขั้นตอนที่ 1: Fuzzify เพื่อแปลงค่าอินพุตจริงเป็นเกรดความจริงฟัซซีของอุณหภูมิและความชื้น |
| **15** | `activation = engine.evaluate_rules(mu_temp, mu_humid)` | เรียกขั้นตอนที่ 2 & 3: ประเมินกฎฟัซซีควบคุม 4 ข้อ และหาความสูงของการกระตุ้นความเร็วพัดลม |
| **18** | `speed = engine.defuzzify(activation)` | เรียกขั้นตอนที่ 4: Defuzzify คำนวณหาน้ำหนักศูนย์กลางความเร็วพัดลมจริงออกมาเป็นเปอร์เซ็นต์ |
| **21-28**| `print(...)` | แสดงข้อมูลรายงานสรุปผลลัพธ์การประมวลผลอย่างละเอียดทีละขั้นตอนออกหน้าจอเพื่อส่งเสริมความเข้าใจของผู้เรียน |
| **30** | `if __name__ == "__main__":` | บล็อกตรวจสอบการสั่งรันโปรแกรมว่าถูกรันโดยตรง (ไม่ได้รันผ่านการอ้างอิงนำเข้า) |
| **31** | `print("=== ... ===")` | พิมพ์หัวข้อต้อนรับเข้าสู่โปรแกรมจำลองระบบควบคุมพัดลม |
| **32** | `try:` | บล็อก `try-except` สำหรับดักจับความผิดพลาดหากผู้ใช้พิมพ์ค่าที่ไม่ใช่ตัวเลขเข้ามา |
| **34** | `temp_input = float(input(...))` | แสดงข้อความถามและรับค่าอุณหภูมิจากผู้ใช้ แล้วแปลงเป็นทศนิยม (`float`) |
| **35** | `humid_input = float(input(...))` | แสดงข้อความถามและรับค่าความชื้นจากผู้ใช้ แล้วแปลงเป็นทศนิยม (`float`) |
| **38** | `run_simulation(temp_input, humid_input)` | เรียกฟังก์ชันประมวลผลจำลองโดยส่งค่าที่ผู้ใช้กรอกเข้ามา |
| **39-40**| `except ValueError:` | หากเกิดข้อผิดพลาดในการแปลงข้อมูล (เช่น ผู้ใช้พิมพ์ตัวอักษรภาษาอังกฤษ) ให้พิมพ์แจ้งเตือนความผิดพลาดสีแดงออกมา |
