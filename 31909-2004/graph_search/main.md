# อธิบายการทำงานของ `main.py` ทีละบรรทัด

ไฟล์ `main.py` ทำหน้าที่เป็นจุดเริ่มต้นของแอปพลิเคชัน คอยรับคำสั่ง วิเคราะห์โหนด รันกระบวนการค้นหา และสั่งเปรียบเทียบ:

---

| บรรทัดที่ | โค้ด | คำอธิบาย |
| :---: | :--- | :--- |
| **1-12** | `""" ... """` | คอมเมนต์อธิบายหน้าที่หลักของไฟล์นี้และไวยากรณ์ในการป้อนสั่งงานผ่าน CLI |
| **14** | `import sys` | นำเข้าระบบเพื่อเข้าถึงระบบปฏิบัติการและอาร์กิวเมนต์ที่พิมพ์ตอนรันโปรแกรม |
| **16** | `import matplotlib.pyplot as plt` | ดึงตัวแปรระบบวาดพล็อตแสดงผลรูปภาพ |
| **18** | `from graph_builder import build_graph` | นำเข้าฟังก์ชันดึงกราฟและจุดเริ่ม/เป้าหมาย |
| **19** | `from bfs import bfs` | นำเข้าฟังก์ชัน BFS ค้นหาแบบแนวกว้าง |
| **20** | `from dfs import dfs_recursive` | นำเข้าฟังก์ชัน DFS แบบเรียกตัวเองซ้ำ |
| **21** | `from astar import astar` | นำเข้าฟังก์ชัน A* แบบใช้ heuristic คาดการณ์ |
| **22** | `from visualize import draw_comparison` | นำเข้าฟังก์ชันพล็อตภาพจัดบานเปรียบเทียบ |
| **25** | `def path_cost(G, path):` | ประกาศฟังก์ชันรวบรวมต้นทุนเส้นเชื่อม (Weight) ตลอดแนวเส้นทางเดิน |
| **27** | `if not path or len(path) < 2:` | ถ้าไม่มีเส้นทางเดินหรือเดินไปมีไม่ถึงสองโหนด (ไม่มีเส้นเชื่อม) |
| **28** | `return 0.0` | คืนราคาต้นทุนเป็นศูนย์ |
| **29** | `return round(sum(...), 2)` | คำนวณผลรวมน้ำหนักเส้นเชื่อมและส่งค่าปัดทศนิยม 2 ตำแหน่ง |
| **32** | `def ask_nodes(G):` | ประกาศฟังก์ชันถามอินพุตจากแป้นพิมพ์เมื่อไม่ได้ส่งอาร์กิวเมนต์ผ่าน CLI |
| **34** | `nodes = sorted(G.nodes())` | ดึงรายการโหนดทั้งหมดมาจัดเรียงตามลำดับตัวอักษร |
| **35** | `print("โหนดที่มีในกราฟ:", ...)` | แสดงโหนดตัวอย่างที่มีให้เลือกพิมพ์ใน Terminal |
| **36** | `while True:` | วนลูปถามอินพุตไปเรื่อย ๆ จนกว่าจะได้คู่โหนดที่ถูกต้องจริง |
| **37-38**| `start = ... / goal = ...` | รับค่าผ่านแป้นพิมพ์ ทำการตัดช่องว่างปลายสองฝั่ง และแปลงเป็นตัวพิมพ์ใหญ่ |
| **39** | `ok, msg = validate_nodes(G, start, goal)` | ตรวจสอบว่าโหนดเริ่มต้นและปลายทางที่กรอกมานั้นอยู่ในกราฟจริงหรือไม่ |
| **40** | `if ok:` | หากถูกต้องใช้งานได้ |
| **41** | `return start, goal` | ส่งโหนดสตาร์ทและเป้าหมายนั้นกลับไปรันการค้นหา |
| **42** | `print(...)` | หากโหนดพิมพ์เพี้ยน ให้ส่งข้อความแจ้งเตือนสีส้ม แล้ววนขึ้นไปรับค่าพิมพ์ใหม่ |
| **45** | `def validate_nodes(G, start, goal):` | ประกาศฟังก์ชันตรวจสอบว่าสองโหนดนี้มีตัวตนอยู่บนกราฟจริงหรือไม่ |
| **47** | `for name in (start, goal):` | วนลูปสองตัวแปรร่วม |
| **48** | `if name not in G:` | ถ้าไม่พบในชุดโหนดของกราฟ `G` |
| **49** | `return False, f"..."` | คืนค่าปฏิเสธเป็น `False` พร้อมบอกเหตุผลว่าไม่พบโหนดชื่อนี้ |
| **50** | `return True, ""` | คืนค่า `True` ยืนยันความปลอดภัยในการรันถัดไป |
| **53** | `def get_nodes(G, argv):` | ประกาศฟังก์ชันกรองและถอดหาคู่โหนดเริ่มต้นกับโหนดเป้าหมายจากรายการอาร์กิวเมนต์ |
| **55** | `positional = [a.upper() for a in argv if not a.startswith("-")]` | คัดเลือกเอาเฉพาะอาร์กิวเมนต์ที่ไม่มีขีดหน้า (เช่น คัดเอาโหนด A และ I) |
| **56** | `if len(positional) >= 2:` | ถ้าผู้ใช้ป้อนโหนดสตาร์ทและปลายทางเข้ามาอย่างน้อยสองตัว |
| **57** | `start, goal = positional[0], positional[1]` | นำพารามิเตอร์คู่แรกมาเป็นจุดเริ่มต้นและปลายทาง |
| **58** | `ok, msg = validate_nodes(G, start, goal)` | เรียกเช็กความถูกต้องในกราฟทันที |
| **59-60**| `if not ok: raise SystemExit(msg)` | หากเลือกโหนดผิด ให้ปิดระบบรายงานเออเร่อทันทีและแนะตัวเลือกโหนดที่มี |
| **61** | `return start, goal` | คืนค่าโหนดคู่แรกที่ป้อนมา |
| **62** | `return ask_nodes(G)` | หากผู้ใช้รันเปล่า ๆ ไม่ป้อนโหนด ให้วิ่งเข้าระบบ interactive ถามตอบ |
| **65** | `def run_search(G, start, goal, save_only=False):` | ประกาศฟังก์ชันสำหรับประมวลผลอัลกอริทึมทั้ง 3 แบบเปรียบเทียบกัน |
| **67** | `bfs_path, bfs_order = bfs(G, start, goal)` | รันอัลกอริทึม BFS ค้นแนวกว้าง |
| **68** | `dfs_path, dfs_order = dfs_recursive(G, start, goal)` | รันอัลกอริทึม DFS ค้นลึกลงไป |
| **69** | `astar_path, astar_order, astar_cost = astar(G, start, goal)` | รันอัลกอริทึม A* ค้นหาที่ดีสุดด้วยระยะทางตรง Heuristic |
| **71-74**| `print(...)` | พิมพ์เส้นแบ่งข้อความรายละเอียดสรุปคู่โหนด |
| **76** | `if bfs_path is None:` | ตรวจสอบกรณีโหนดสองฝั่งแยกเดี่ยวขาดจากกันในแผนที่ (ไปหากันไม่ได้) |
| **77-78**| `print(...)` | แจ้งเตือนข้อความว่าไม่สามารถเดินไปถึงกันได้ และออกจากฟังก์ชัน |
| **80-82**| `print("[BFS]...")` | พิมพ์ข้อมูลลำดับแวะ และสรุปรายละเอียดขั้นตอนกับต้นทุนสะสมของ BFS |
| **84-86**| `print("[DFS]...")` | พิมพ์ข้อมูลลำดับแวะ และสรุปรายละเอียดขั้นตอนกับต้นทุนสะสมของ DFS |
| **88-91**| `print("[A*]...")` | พิมพ์ข้อมูลลำดับการขยายและต้นทุนสะสมของ A* (ซึ่งการันตีถูกที่สุด) |
| **93-100**| `results = [ ... ]` | รวบรวมข้อมูลผลลัพธ์ของแต่ละอัลกอริทึมในรูปแบบโครงสร้างข้อมูล Dictionary |
| **102** | `save_path = f"..." if save_only else None` | ถ้าเปิดพารามิเตอร์ `--save` ให้ตั้งชื่อไฟล์รูปภาพปลายทาง |
| **103** | `draw_comparison(...)` | สั่งวาดและบันทึก หรือพล็อตรูปภาพลงระบบกราฟิก |
| **104-105**| `if not save_only: plt.show()` | ถ้าไม่ได้สั่งเพื่อบันทึกไฟล์เฉย ๆ ให้เปิดหน้าต่างกราฟิกป๊อปอัปผลลัพธ์ขึ้นมาทันที |
| **108** | `def main():` | ประกาศฟังก์ชันหลักของโมดูลนี้ |
| **109** | `save_only = "--save" in sys.argv` | ตรวจค้นว่าในคำสั่งมีพารามิเตอร์สั่งเซฟภาพอย่างเดียวหรือไม่ |
| **110** | `G, _, _ = build_graph()` | เรียกใช้งานตัวจำลองกราฟตั้งต้นขึ้นมา |
| **111** | `start, goal = get_nodes(G, sys.argv[1:])` | ตรวจกรองหรือถามคู่โหนดจากประวัติผู้ใช้ |
| **112** | `run_search(G, start, goal, save_only=save_only)` | สั่งรันการเปรียบเทียบประมวลผลและการแสดงรูปภาพ |
| **115-116**| `if __name__ == "__main__": main()` | สั่งรันฟังก์ชันหลัก main() เมื่อป้อนโปรแกรมรันตัวนี้ตรง ๆ |
