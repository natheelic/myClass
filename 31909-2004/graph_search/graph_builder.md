# อธิบายการทำงานของ `graph_builder.py` ทีละบรรทัด

ไฟล์ `graph_builder.py` ทำหน้าที่สร้างโครงสร้างกราฟและกำหนดคุณสมบัติของโหนดและเส้นเชื่อม ดังนี้:

---

| บรรทัดที่ | โค้ด | คำอธิบาย |
| :---: | :--- | :--- |
| **1-9** | `""" ... """` | คอมเมนต์อธิบายหน้าที่หลักของไฟล์นี้ |
| **11** | `import math` | นำเข้าโมดูล `math` เพื่อใช้ฟังก์ชันคณิตศาสตร์ในการหาค่าสแควร์รูทหรือหาระยะทางตรง |
| **12** | `import networkx as nx` | นำเข้าไลบรารี `networkx` ย่อเป็น `nx` เพื่อใช้สร้างและจัดการโครงสร้างข้อมูลกราฟ |
| **15** | `def euclidean(p1, p2):` | ประกาศฟังก์ชันหาตวามยาวเส้นตรงระหว่างจุด 2 จุด (พิกัด $p_1$ และ $p_2$) |
| **16** | `"""..."""` | Docstring อธิบายการใช้ประโยชน์ของฟังก์ชันนี้ |
| **17** | `return math.hypot(p1[0] - p2[0], p1[1] - p2[1])` | ใช้สูตร Euclidean Distance ด้วย `math.hypot` คืนค่าระยะขจัดเส้นตรง |
| **20** | `def build_graph():` | ประกาศฟังก์ชันหลักในการสร้างออบเจกต์กราฟ |
| **21-26**| `"""..."""` | Docstring อธิบายโครงสร้างของกราฟที่จะจำลองขึ้นมา (12 โหนด A-L) |
| **27** | `G = nx.Graph()` | สร้างออบเจกต์กราฟแบบไม่มีทิศทาง (Undirected Graph) |
| **30-43**| `positions = { ... }` | ประกาศดิชันนารีเก็บคีย์เป็นชื่อโหนด และค่าเป็นพิกัดคาร์ทีเซียน $(x, y)$ |
| **46** | `for node, pos in positions.items():` | วนลูปคู่ข้อมูลโหนดและพิกัดที่มีอยู่ในตัวแปร `positions` |
| **47** | `G.add_node(node, pos=pos)` | เพิ่มโหนดเข้าไปในกราฟ `G` พร้อมเก็บพิกัดใน attribute ชื่อ `pos` |
| **50-59**| `edges = [ ... ]` | ลิสต์ของคู่โหนดที่ต้องการให้มีเส้นเชื่อมต่อถึงกัน |
| **62** | `for u, v in edges:` | วนลูปคู่โหนดต้นทาง $u$ และโหนดปลายทาง $v$ ในลิสต์เส้นเชื่อม |
| **63** | `w = euclidean(positions[u], positions[v])` | คำนวณหาระยะห่างตรงระหว่างโหนด $u$ และ $v$ |
| **64** | `G.add_edge(u, v, weight=round(w, 2))` | เพิ่มเส้นเชื่อมเชื่อมระหว่าง $u$ และ $v$ กำหนดน้ำหนักปัดทศนิยม 2 ตำแหน่ง |
| **66** | `return G, "A", "L"` | คืนค่าตัวกราฟ `G`, ชื่อโหนดเริ่มต้น `"A"`, และโหนดปลายทาง `"L"` |
| **69** | `def get_positions(G):` | ประกาศฟังก์ชันสำหรับดึงข้อมูลพิกัดทั้งหมดของกราฟ |
| **70-71**| `return nx.get_node_attributes(G, "pos")` | ดึงคุณสมบัติพิกัด `pos` ของทุกโหนดออกมาเป็นดิชันนารีแล้วคืนค่ากลับไป |
| **74** | `if __name__ == "__main__":` | บล็อกตรวจสอบการสั่งรันสคริปต์นี้โดยตรงจากเทอร์มินัล |
| **75** | `G, start, goal = build_graph()` | เรียกใช้ฟังก์ชัน `build_graph()` เพื่อดึงกราฟและข้อมูลเริ่มต้นออกมา |
| **76** | `print(...)` | แสดงจำนวนและรายชื่อโหนดทั้งหมดที่เรียงลำดับแล้ว |
| **77** | `print(...)` | แสดงจำนวนของเส้นเชื่อมในกราฟทั้งหมด |
| **78** | `for u, v, data in G.edges(data=True):` | วนลูปเส้นเชื่อมทั้งหมดพร้อมข้อมูลคุณสมบัติของเส้นเชื่อมนั้น ๆ |
| **79** | `print(f"  {u} -- {v}  (weight={data['weight']})")` | พิมพ์รายงานชื่อโหนดคู่เชื่อมพร้อมระบุน้ำหนัก |
| **80** | `print(...)` | พิมพ์แสดงโหนดเริ่มต้นและเป้าหมายเริ่มต้นสำหรับการทดสอบรัน |
